# Flag artwork

The 4:3 SVG flags are vendored from **flag-icons 7.3.2** by Panayiotis Lipiridis
and contributors: https://github.com/lipis/flag-icons/tree/v7.3.2/flags/4x3

Source archive: https://registry.npmjs.org/flag-icons/-/flag-icons-7.3.2.tgz

Only the countries/regions used by the city catalog are included. No external
requests or flag library are required at runtime. See LICENSE for the MIT license.
